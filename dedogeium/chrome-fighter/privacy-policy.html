Screen Fighter Privacy Policy

Last updated: April 4, 2026

Screen Fighter is a browser extension that adds a doge battle mini-game overlay to webpages and includes a popup link to ryancherches.com/dedogeium.

Information the extension uses

Screen Fighter does not sell personal information and does not use personal information for advertising.

The extension may access or store the following data locally on your device:

  • Your on/off preference for enabling or disabling the extension.
  • Local battle-related settings and temporary game state.
  • Dedogeium-related game data already stored in your browser, such as local stats, inventory, equipped items, and currency, when needed for game features.
  • Temporary local reward sync data used to apply earned in-game currency to Dedogeium later.

How the extension uses data

  • To display the Screen Fighter mini-game on webpages.
  • To remember whether you have disabled or enabled the doge overlay.
  • To read local Dedogeium game stats so battles can reflect your current doge strength.
  • To save temporary local reward data and apply it to Dedogeium on supported pages.

Storage and permissions

Screen Fighter uses the Chrome storage permission to save extension settings and local game-related state. The extension also runs on webpages so it can place the doge battle overlay where the user expects to see it.

Data sharing

Screen Fighter does not sell your data and does not share your data with third parties for advertising, profiling, or analytics. Data used by the extension is intended only to provide the extension's gameplay and user settings.

Remote code

Screen Fighter does not use remote code. Its core extension logic is packaged with the extension itself.

Third-party websites

This extension can interact with webpages, including Dedogeium pages hosted at ryancherches.com. Those websites may have their own privacy practices, which are separate from this extension.

Changes to this policy

This Privacy Policy may be updated from time to time. When changes are made, the updated version will be posted with a new “Last updated” date.

Contact

For questions about this Privacy Policy, use the developer contact email listed for Screen Fighter in the Chrome Web Store listing.
